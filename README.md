## 最重要的三个时间点

1. **7月20日 14:30**：必须离开 Landmannalaugar，赶 19:00 西人岛渡轮；车辆最迟提前 30 分钟 check-in。
2. **7月25日**：住宿在 Suðureyri，不是 Hólmavík；从 Hólmavík 仍有约 3 小时级别转场。
3. **7月26日 17:00–17:15**：抵达 Brjánslækur 等待 18:00 Baldur；7月24日再次复核临时船舶公告。

目前已知固定支出约 **¥74,517/全团**；加上 8 人 Silfra、Húsavík 观鲸和 Earth Lagoon 后，已知预算约 **¥94,217–¥95,084/全团**，即 **¥11,777–¥11,886/人**。燃油、餐食、机票、Blue Lagoon 等机动支出不在这个数字里。

最后原则仍然很简单：天气、道路、体力和安全优先。可选景点宁可删，不拿轮渡、入住和疲劳驾驶去赌。
