## 三个最需要记住的时间

1. **7月20日 14:30**：我们得从 Landmannalaugar 往码头走，赶 19:00 去西人岛的船；带车最晚提前 30 分钟 check-in。
2. **7月25日**：这晚住 Suðureyri，不是 Hólmavík；到了 Hólmavík 以后还要继续开大约 3 小时，这天会比较累。
3. **7月26日 17:00–17:15**：我们到 Brjánslækur 等 18:00 的 Baldur。7月24日我会再看一次有没有临时船舶公告。

车、住宿和两段轮渡目前一共约 **¥74,517/全团**；再加上 8 人 Silfra、Húsavík 观鲸和 Earth Lagoon，这趟旅行现在能算到的部分约 **¥94,217–¥95,084/全团**，也就是 **¥11,777–¥11,886/人**。燃油、吃饭、机票和 Blue Lagoon 这些还没放进去，到时候直接记账就好。

我把时间写得比较细，主要是让两辆车知道大概节奏，不是要大家按分钟打卡。天气、道路、体力和安全还是最重要的；如果那天累了，我们就少去一个点，不为了赶景点影响坐船、入住或者疲劳驾驶。
